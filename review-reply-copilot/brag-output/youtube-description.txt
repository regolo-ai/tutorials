DESCRIPTION (paste as is)
Draft replies to customer reviews in your client's voice with Clef-Flash, an LLM and a person who approves every answer.

What we cover in this tutorial
Answering every review takes time, and a templated reply can do more harm than no reply at all. In this video we walk through Review Reply Copilot, an open source app where Clef-Flash labels each review and checks each draft, a chat model writes the reply with the client's brand rules, and nothing is published until a person approves it.

Key architecture and workflow
• Connect a Regolo account: the API key is verified against the model catalog and stored only in a local .env file
• One brand profile per client: voice, topics, the only facts a reply may state, forbidden phrases
• Clef-Flash labels every review: sentiment, topic, escalation, reply priority and language, eight requests in parallel
• A chat model (qwen3.8-27b) drafts the reply in the client's voice
• Guardrails on every draft: rule checks plus Clef-Flash yes or no checks for compensation promises, blame, personal data, tone, competitors and unsupported claims
• Risky reviews (injuries, legal threats, privacy requests) get a neutral holding reply and go to a person
• Measured in this run (October 15, 2026, 37 synthetic sample reviews, one run): 37 reviews labeled in 3.0 s for $0.0047, replies drafted and checked in 1.7 s on average
• Stack: Python • FastAPI • SQLite • vanilla JS • Clef-Flash and qwen3.8-27b on Regolo EU cloud
